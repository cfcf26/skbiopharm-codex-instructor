# 예산 집행 대시보드

이 스킬의 `assets/dashboard.html`을 원본으로 사용한다. 기존 화면과 계산 로직은 템플릿에 포함되어 있다.

## 입력 및 생성

1. 사용자가 선택한 `.xlsx`에서 `데이터` 시트를 확인한다. 첫 행의 필수 열은 `부서`, `계정 대분류`, `월`, `예산 (억 원)`, `집행액 (억 원)`이다. 열 순서와 추가 열은 자유다. 부서와 월은 비어 있지 않은 문자열이며 월은 기존 형식인 `YYYY-MM`을 사용한다. 대분류는 `인건비`, `경비`, `외주비`, `마케팅비`다. 금액은 억 원 단위의 숫자 셀이다. 시트나 열이 없거나 값이 호환되지 않으면 위치와 사유를 알려 준다. 매핑이나 금액 단위를 임의로 바꾸지 않는다.
2. 스킬 폴더의 스크립트에 원본 엑셀과 새 출력 폴더를 전달한다. 엑셀의 가상 데이터 여부가 확인됐으면 `--sample`을 추가한다.

   ```text
   node "<스킬 폴더>/scripts/build-dashboard.cjs" "<입력.xlsx>" "<새 출력 폴더>" [--sample]
   ```

3. 출력 폴더의 `예산집행-대시보드.html`과 `lib/`를 함께 전달한다. 브라우저에서 HTML을 열면 전달받은 엑셀이 자동으로 표시되며 **엑셀 파일 열기**로 같은 형식의 다른 파일을 불러올 수 있다. HTML에 입력 엑셀 전체가 들어 있으므로 전달 범위는 원본 엑셀과 동일하게 취급한다.

## 집계 및 확인

- 월·부서·대분류 필터를 함께 적용한다. 총예산과 총집행액은 선택 행의 합계, 잔액은 예산 빼기 집행액, 집행률은 총집행액 나누기 총예산이다. 예산이 0이면 집행률을 `—`로 표시한다. 각 금액은 정수 원으로 반올림한 뒤 합산하고 억 원 단위로 표시한다.
- 상단 초과 표는 필터 적용 후 부서와 대분류 조합별로 합산한다. 집행액에서 예산을 뺀 값이 양수인 조합만 초과액 내림차순으로 표시한다. 월 필터가 전체라면 전체 월을 합산한다.
- 월별·대분류별 차트에서는 예산과 집행액을 비교한다. 상세 표에는 월, 부서, 대분류, 예산, 집행액, 잔액, 집행률을 표시한다.
- 전체 합계와 대표 필터 조합을 원본 행으로 대조한다. 브라우저에서 자동 로드, 필터 초기화, 엑셀 교체가 동작하는지 확인한다.
