# README 작성

다른 사람이 이 폴더를 처음 받아도 바로 열어 볼 수 있도록 README.md를 쓴다.

## 지킬 규칙

- README.md가 이미 있으면 **기존 내용은 지우지 않고** 빠진 항목만 아래에 추가한다.
- 폴더에 실제로 있는 파일만 적는다. 없는 파일을 안내하지 않는다.
- 실명, 연락처, 키나 비밀번호를 적지 않는다.
- 쓴 뒤에 README에 적은 파일이 폴더에 모두 있는지 한 번 더 확인한다.

## 담을 내용

1. **제목과 한 줄 설명**: 무엇을 하는 결과물인지
2. **여는 방법**: 어떤 파일을 브라우저나 엑셀로 열면 되는지
3. **파일 목록**: 주요 파일과 하는 일 (예: `대시보드.html` 대시보드 화면, `lib/` 엑셀을 읽는 라이브러리)
4. **데이터**: 어떤 데이터를 쓰는지, 가상 데이터인지
5. **바꾼 이력**: 날짜별로 무엇을 바꿨는지 한 줄씩 (Git 커밋 이력을 참고)

## 끝나면

작성한 README.md 내용을 보여 주고, 커밋은 사용자가 요청할 때만 한다.
